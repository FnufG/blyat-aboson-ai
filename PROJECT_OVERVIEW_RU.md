# What Liniya contains

Liniya is an English browser-based support assistant for one workspace. It uses your uploaded company information and starts with no demonstration data. The source is distributed through `FnufG/blyat-aboson-ai`; a public hosted app is not deployed.

- **Knowledge base:** import TXT/Markdown, add/edit/delete answers and export backups.
- **Test chat:** English grounded answers generated by local Qwen with supporting sources.
- **Voice conversation:** English Whisper recognition, the same local answer service, speech playback, transcription and mute/disconnect controls.
- **Speech output:** Boson when configured, otherwise clearly labelled English eSpeak test speech.
- **Error feedback:** failed questions stay visible; voice errors identify recognition, generation or speech output failures.

No OpenAI key or paid LLM quota is required for the local distribution. Boson is still an optional external voice API. Docker pins local model settings and overrides stale cloud values in `.env.local`; saved keys are not included in source archives.

## Files

```text
app/               Next.js pages, styles and API routes
components/        LiveKit voice panel
lib/               knowledge validation and answer/voice service adapters
voice/             Python API, worker, English recognition and local generation
scripts/           model installation, process lifecycle and diagnostics
tests/             application and browser checks
Dockerfile         reproducible container build
compose.yaml       local Qwen/Whisper runtime
START_WINDOWS.cmd  Windows startup without an OpenAI prompt
STOP_WINDOWS.cmd   Windows stop
CONFIGURE_KEYS_WINDOWS.cmd optional masked Boson key setup
LOCAL_RUN.md       Windows install/update and troubleshooting
.env.example       settings names without actual keys
```

Runtime dependencies, model files and local state live in ignored `.local/`, `node_modules/`, `voice/.venv/` and `.next/`. They are downloaded/built on first setup and excluded from the source distribution.

## Open the interface

Follow [LOCAL_RUN.md](LOCAL_RUN.md), start Docker Desktop, then run `START_WINDOWS.cmd`. Setup downloads missing Qwen/Whisper weights (about1.3GB total) and reuses cached volume data. The interface opens at http://localhost:3000 on your computer. Wait for model readiness, upload your company information, then test text before voice.

When upgrading, stop the old app, replace files in the same folder while keeping `.env.local`, then start again. Your browser's custom knowledge is retained. Do not remove the Docker volume for an ordinary upgrade.

This is a single-workspace MVP rather than a multi-company SaaS. Permanent knowledge and text history live in your browser; temporary voice-room knowledge is isolated in local SQLite. Accounts, subscription billing and telephone routing are outside the current scope.
